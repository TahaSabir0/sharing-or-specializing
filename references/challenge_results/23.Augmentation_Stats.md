# 23. Modality-aware image augmentation — a transferable train-time data-manipulation delta

**Scope.** The one broad, untried, *transferable* training-data manipulation left for cls/ML after the
data-manipulation well ran dry (rebalancing spent, donor co-training low-prior — see `PROGRESS.md`
2026-08-03, `stats/22`). Augmentation targets the **UNSTRUCTURED-perception** failure (`stats/16 §2e`:
bcn20000, fundus-age — errors with no directional structure, i.e. plausibly overfit/perception-limited)
that duplication and reshuffling provably can't touch. Narrative + decisions: `PROGRESS.md` 2026-08-03.
Branch `Taha/augmentation` (off `Taha/all-data-retrain`, which carries the `stats/21` recipe screen).

**★ Key property — augmentation is TRAIN-ONLY.** It is a regularizer applied to the training image stream;
the inference path is **untouched**. So (unlike Alberto's preprocessing, `stats/17`) it needs **no
inference change, no train/infer byte-identity gate, no modality classifier at inference** → far lower
ship-risk. The only correctness requirements are (a) applied **on-the-fly, re-randomized every epoch**
(NOT baked into the exported deck), and (b) **modality-gated** so transforms never break medical semantics.

- **★ Decision lens (per `stats/22`):** read the delta **per dataset**, focused on the UNSTRUCTURED-
  perception sets (**cls: bcn20000, fundus**; ML: periapical/chestdr), and **weighted to the true-test
  slice, not the board.** Accept only if it helps the target datasets without regressing the strong ones
  (dental, retino). A whole-deck aug that hurts a strong dataset ⇒ tighten the modality gate.

## The modality gate (train-time, keyed by dataset → modality)

| modality (datasets) | flips | rotation | photometric | notes |
|---|---|---|---|---|
| dermatology (bcn20000), microscopy (bone_marrow) | H **+ V** | ±deg | color + intensity jitter | no canonical orientation |
| fundus / retino (fundus, retino) | H only | small | mild brightness/contrast | preserve vessel/hemorrhage color |
| mammography (CMMD) | **none** | small | intensity-window jitter | L/R laterality is **labeled** → no flip |
| X-ray (dental, chestdr, bone_marrow-xr, boneresorption) | **none** | small ±deg | intensity jitter | anatomy orientation matters |
| ultrasound (BUSI, BUS-UCLM, iugc) | none (careful) | small | intensity jitter | + mild crop |

*(Geometric transforms are for cls/ML only. Detection/regression/counting decks are NOT augmented
geometrically — coordinate risk, zero upside, per `stats/17`.)*

### ★★ Reading — a macro NULL that is NOT an uninformative null

**Whole-deck modality-gated augmentation is a wash on the headline (+0.0018/+0.0032, below the 0.005
direction-noise floor) — because the winners and losers CANCEL.** 5 of 10 datasets are **sign-consistent in
both directions**, which is the real signal: winners `bone_marrow` + `fundus`, losers `bcn20000` + `CMMD` + `iugc`.

**★ MECHANISM (supersedes the unstructured-perception hypothesis this screen was designed on):**
> **Augmentation helps when the transform is a TRUE INVARIANCE of the diagnostic task; it hurts when the
> transform destroys the diagnostic signal itself.**
- **microscopy (bone_marrow) wins big** — a blood cell has no canonical orientation ⇒ flips/rotations are
  genuinely label-preserving.
- **fundus wins** — left/right eyes both occur ⇒ H-flip is a real invariance.
- **dermoscopy (bcn20000) LOSES** — **color variegation IS a melanoma diagnostic criterion**; color jitter
  erases diagnostic signal.
- **mammography (CMMD) LOSES** — **intensity IS the signal** (density, calcifications); intensity-window
  jitter erases it.
- **ultrasound/iugc LOSES** — geometric relations carry fetal biometry; rotation/crop corrupts them.

**⚠️ A PRIOR WAS FALSIFIED, instructively.** This screen predicted gains on the *unstructured-perception*
sets (`bcn20000`, `fundus`, `stats/16 §2e`). **`fundus` delivered; `bcn20000` went consistently the WRONG WAY**,
and the largest gain landed on **`bone_marrow`, which was never a target.** The design error: the gate was
chosen by **modality safety** (don't flip labeled laterality) rather than by **what carries the diagnostic
information**. The correct gating axis is *signal-preservation*, not *orientation-plausibility*.

**★ The train-loss ambiguity is RESOLVED in favour of the benign reading.** Loss 0.1401/0.1476 (~230×
baseline's 0.0006) produced **no held-out collapse** — unlike `stats/21`'s genuinely non-converged arms at
comparable loss (loraplus 0.1282 → −0.260, rank64@2e-4 0.1318 → −0.293). ⇒ **high train loss under
augmentation is the regularization mechanism, not destroyed signal, and `stats/21`'s "high loss = didn't
converge" rule does NOT transfer across a change in the DATA STREAM** (it was derived for optimizer/capacity
changes at fixed data). Method note worth keeping.

## §1b — SIGNAL-PRESERVING gate + oversampling-interaction arm — **LAUNCHED 2026-08-03** (results pending)

**The refinement.** §1 bundled **geometric** (flips/rotation) and **photometric** (color/intensity jitter)
transforms into one per-modality policy. The §1 results say the two families act **oppositely** depending on
modality ⇒ **factorize them.** New gate mode `AUG_MODE=signal_preserving` (the original `modality_gated` is
left untouched so §1 stays reproducible):

| modality | `signal_preserving` policy | why |
|---|---|---|
| microscopy (bone_marrow) | **UNCHANGED** (flips + rot + photometric) | the one place photometric demonstrably helped (§1a verified) — don't touch it |
| fundus/retina (fundus, retino) | **UNCHANGED** (H-flip + small rot + mild brightness) | fundus won |
| **dermoscopy (bcn20000)** | **GEOMETRIC-ONLY** (drop color+intensity jitter) | a lesion under a lens has no canonical orientation ⇒ flips/rot are valid; **color variegation IS a melanoma criterion** |
| **X-ray (dental, chestdr, boneresorption)** | **GEOMETRIC-ONLY** (drop intensity jitter) | intensity carries density/contrast; `dental` is **53% of board cls** |
| mammography (CMMD) | **OFF** | intensity IS the signal, and CMMD's ceiling is low (subtype visually ill-posed, `stats/16`) |
| ultrasound (BUSI, BUS-UCLM, iugc) | **OFF** | geometry carries fetal biometry; iugc already ~0.90 (no headroom) |

**★ Arm X — does OVERSAMPLING fight AUGMENTATION?** Taha's observation: **all 3 oversampled datasets (k2a
touches only CMMD / bcn20000 / retino) failed to gain, while both winners were never oversampled.**
- **Statistically this is ~a coin flip:** with 2 winners among 10 datasets and 3 oversampled,
  P(neither winner is oversampled) = C(7,2)/C(10,2) = **0.467**. Not evidence on its own.
- **Two facts cut against causation:** `iugc` **lost and was never oversampled**; and `retino` **is**
  oversampled but received a *gentle* transform (H-flip + mild brightness, no photometric jitter) and came out
  **neutral, not negative** — if oversampling were the blocker, retino should have lost too.
- **The confound is near-total:** the oversampled set overlaps almost exactly with the "got a
  signal-destroying photometric transform" set (CMMD→intensity jitter, bcn20000→color jitter).
- **But a real mechanism exists:** a rare class with ~37 unique images duplicated 6× where every copy is
  transformed differently may exceed the LoRA's capacity — oversampling and augmentation could compete.
⇒ **Arm X = Arm G with bcn20000's oversampling REMOVED** (CMMD + retino oversampling retained ⇒ single
variable vs G). Single-direction on purpose — a diagnostic, not an adoption candidate.
