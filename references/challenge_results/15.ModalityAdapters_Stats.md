### §4 VERDICT — standalone modality adapters do NOT beat the deployed specialists
- **Classification (~50% of ranking): clear loss** — modality adapters are a data-starved, multi-task-diluted
  subset of the cls specialist. Do NOT route cls to them.
- **Detection / counting: specialist ≥ modality > `general`.** Modality-concentration beats the all-modality
  generalist but not the task specialist → no deployment case.
- **Regression: ~tie.** iugc identical; a small boneresorption edge vs the (unused) reg-specialist, but `general`
  is the deployed reg route.
- **Multi-label (Xray): the one bright spot** — modality adapter matches/edges the best ML config (tt 0.552 ≈
  deployed 0.550; vp 0.489 > 0.478). Plausibly Xray report-gen + ML co-training sharpening chest multi-label.
- **★ Scientific through-line (paper-worthy):** lever ranking is **task-specialization > modality-concentration >
  general** — modality concentration DOES help vs a fully-mixed general adapter (counting 19.8<24.3, detection
  0.887>0.853, ML 0.552>0.541), but that benefit does not survive against the task specialists.

### Implication for Config 4 (task ⊕ modality merge)
Low EV. The modality adapter carries little the task specialist lacks (it's the weaker model on every slice but
Xray-ML), so merging it into the strong task adapter is more likely to dilute than help — especially on cls. The
**only** slice worth a merge probe is **Xray multi-label**, where the modality adapter is already competitive.
Recommend: park the full Config-4 merge; optionally test a task⊕modality merge on the Xray-ML route only.

|---|--:|--:|--:|--:|

Per-class P/R/F1 = **1.0 for all 8 modalities** (incl. Endoscopy n=71/368 and the Xray↔Mammography

Integrity: leakage 0 on all 3 pairs, 0 missing files, pretrained=true, A100-40GB, 4,608 s wall.

- **Caveat:** most modalities map ~1:1 to one dataset (Mammography=CMMD, Clinical=neojaundice), so the

- **★ Implication for modality-tag conditioning: NEGATIVE evidence.** A 43 MB ResNet recovers modality

- **★ Implication for modality-gated PREPROCESSING: POSITIVE.** Perfect, cheap, well-calibrated routing
  (vs Alex's MedSigLIP at 80–83% fire / 0.75–0.78 mean conf) → gating rails become near-trivial.

### §6a. Verification of the 100% (Taha flagged it as suspicious — 4 independent checks, 2026-07-26)
100% on 10,511 held-out images warranted an audit. **Result: the number is REAL.**
1. **Metrics bug? NO.** Independent recompute from raw `predictions_*.jsonl`: **3702/3702**, **6809/6809**.
   Rows carry distinct absolute paths + full 8-way prob vectors; lowest-conf cases (0.38–0.41) are correct.
2. **Path leakage? NO.** Train index rebuilt independently from `{A,B}.jsonl` (33,616 — matches) →
   **0 path overlap** with either eval split.
3. **Content-level duplicates? Tiny.** MD5(first 64 KB) on samples: **9/2500 (0.36%) true_test**,
   **3/2500 (0.12%) valpub**. Two kinds: (a) intra-dataset dupes under different names
   (`Retino_00951 ↔ Retino_01010`); (b) same-basename across `training/` vs `validation-public/`
   (`BUSI_00327.png`) = residue of the known renumbered-duplicate issue that `internal_splits_v2`
   de-dup did NOT fully catch. **0.1–0.4% cannot explain 100% on 10,511** → not the cause.
   *(Minor standing data-quality note for other evals; magnitude is negligible.)*
4. **Resolution/aspect shortcut? NO — structurally impossible.** The trainer does a **hard square resize
   to 2048×2048** (`.resize((res,res), BILINEAR)`), so every input has identical dimensions and aspect is
   destroyed; the model cannot see original size. *(Notable anyway: raw dimensions alone would separate
   **~85.8%** of a 1,200-image sample — only one ambiguous size, 512×512 shared by Ultrasound/Xray.)*

**Conclusion: the task is genuinely trivial** — 8 visually enormous-different image types (567² RGB baby
photos, 1024² dermoscopy, 1914×2294 grayscale mammograms, circular fundus, cell slides, ultrasound cones,
endoscope interiors, X-rays) is far easier than the ImageNet 1000-way problem the ResNet-18 was pretrained on.
**Surviving caveat (sharpened, for the paper):** modality ≈ dataset ≈ acquisition protocol, and dims alone
reach ~86%, so the net likely keys on **scanner/protocol signature** as much as clinical modality → expect it
NOT to transfer to an unseen scanner, though it is valid for FLARE (100% on validation-public, a true
organizer holdout).
